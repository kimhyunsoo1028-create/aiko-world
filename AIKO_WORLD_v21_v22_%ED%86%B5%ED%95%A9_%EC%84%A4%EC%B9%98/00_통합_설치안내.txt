愛子 WORLD v2.1 + v2.2 한 번에 설치하기
======================================

두 기능을 모두 설치하는 통합 ZIP입니다.
v2.1: 「이어지는 시간, 쌓이는 노래」 일반 사진/영상 아카이브
v2.2: 야마노테이션·OVAL·솔로 등 공연별 세트리스트/사진/영상 기록

[0] 백업
- Netlify 현재 Build command 원문을 메모장에 백업하세요.
- 기존 공연 일정, 방송 영상, Supabase 데이터는 지우지 마세요.
- 과거 설치 명령에 v2.1 또는 v2.2 설치가 이미 들어 있으면 중복해서 추가하지 마세요. 둘 다 설치되지 않았다면 아래 순서로 진행하세요.

[1] Supabase (최초 한 번)
1. https://supabase.com/dashboard/ → 기존 愛子 WORLD 프로젝트
2. SQL Editor → New query
3. AIKO_WORLD_v21_v22_통합_설정.sql 전체 내용 복사 → Run
4. 마지막 결과에 v21+v22 ready가 나오면 두 테이블이 준비된 것입니다.
- 기존 history_media 또는 concert_stories 테이블이 이미 있으면 건드리거나 비우지 않고 재사용합니다.
- SQL은 현재 두 프로젝트 파일에서 추출했습니다. 사이트마다 권한 설정이 다를 수 있어 오류 시 오류 문구 확인이 필요합니다.

[2] GitHub (한 번)
1. https://github.com/kimhyunsoo1028-create/aiko-world
2. Add file → Upload files → AIKO_WORLD_v21_v22_통합_설치.zip 를 압축 해제하지 않고 그대로 업로드
3. Commit changes
- 기존 ZIP / episode-catalog.js / rent-aiko-schedule.js 삭제 금지

[3] Netlify (한 번)
1. https://app.netlify.com 에서 기존 creative-melomakarona-e53d52 프로젝트
2. Project configuration → Build settings → Build command
3. 기존의 정상 동작 중인 Build command 맨 마지막에 다음 내용을 덧붙이세요.

&& unzip -o AIKO_WORLD_v21_v22_통합_설치.zip && node install-aiworld-v21-v22.cjs

4. Save → Deploys → Trigger deploy (GitHub 자동 배포가 됐으면 중복 배포 불필요)
5. Published 확인

주의: 본 명령은 기존 사이트를 만든 다음에 실행해야 합니다. v21 또는 v22 설치 명령을 이미 넣어두었다면 기존 기능과 중복되어 동작에 문제가 생길 수 있으므로, 기존 Build command를 확인한 뒤 통합형 명령으로 대체하거나 기존 명령을 유지하세요. 둘 다 무작정 추가하지 마세요.

[4] 확인
관리자: https://creative-melomakarona-e53d52.netlify.app/admin/
- 🎞️ 발자취 사진·영상 (v2.1)
- 🎼 공연별 세트리스트·사진 (v2.2)
메인: https://creative-melomakarona-e53d52.netlify.app/#history

[5] 자료 입력
공연별 기록 → +새 공연 기록 → 날짜/장소 → 야마노테이션 분류 → 세트리스트 → 사진 여러 장 → 유튜브 링크 여러 개 → 공개 저장
- 확인되지 않은 세트리스트와 영상을 만들어 넣지 마세요.
- 영상 자체 파일을 직접 업로드하는 기능은 없습니다. 유튜브 등 URL 등록을 이용하세요.

[보존 및 검사]
- 본 ZIP에는 public/index.html, public/data.js, public/admin/index.html이 없습니다.
- 기존 사이트 HTML에 CSS/JS 태그만 추가합니다.
- 기존 관리자 DB나 공연 일정을 초기화하지 않습니다.
- 두 설치 스크립트를 로컬에서 각 두 번 실행해 중복 태그가 추가되지 않음을 검사했습니다.
- 실제 사용자의 Netlify 환경에서 SQL/로그인/사진 업로드 성공은 아직 검증하지 못했습니다.
